# Synclo

Turn your notes into designed presentations. Make a presentation from any note, follow it in the Synclo panel as it's written, then edit and share it in Synclo or download it as PowerPoint or PDF.

Requires a Synclo account. New accounts include 400 free credits, enough for about 40 slides. More credits are available at [synclo.app](https://synclo.app/pricing).

## Getting started

1. Install and enable **Synclo** in **Settings → Community plugins**.
2. Open a note and select **Make a presentation from this note** in the ribbon or the command palette.
3. Select **Connect** and sign in to Synclo in your browser.
4. Choose your options and select **Make**.

When it's ready, the presentation's link is saved in the note's properties. Downloads are saved in your vault.

## Commands

- Make a presentation from this note
- Make a presentation from the selection
- Find a presentation
- Open this note's presentation in your browser
- Download this note's presentation as PowerPoint
- Download this note's presentation as PDF

## Privacy

- Synclo is a product of Synclo Inc and is not affiliated with Obsidian.
- A Synclo account is required. Making presentations uses credits; the plugin takes no payments.
- The plugin connects only to synclo.app, and only when you use it. It sends the note you choose, the notes and images it embeds, linked notes if you include them, and your options. You can preview exactly what is sent before you confirm. Nothing else in your vault is read.
- Properties, comments and queries are never sent.
- Your sign-in is stored in Obsidian's secure storage on each device.
- The plugin collects no usage data. See Synclo's [privacy policy](https://synclo.app/privacy).
